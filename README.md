# 🦅 Bercy MCP — Tri-Chain Payment Layer

The payment layer for all AI agents. x402 + AC2 on Algorand + Celo + Solana.

## 8 Tools
- bercy_health — check all 3 chains
- bercy_rates — 95+ live FX corridors
- bercy_convert — any currency pair
- bercy_authorize — AC2 human approval
- bercy_pay_celo — pay on Celo Mainnet
- bercy_pay_algorand — pay on Algorand Mainnet
- bercy_pay_solana — pay on Solana Mainnet
- bercy_best_route — find best chain
